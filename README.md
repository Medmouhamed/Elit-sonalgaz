# ⚡ ELIT-Sonalgaz 

A dedicated web platform developed for **ELIT (Sonalgaz Group)**. This portal serves as a comprehensive digital resource for visualizing Algeria's electricity and gas distribution networks, history, and technical infrastructure.

## 🏢 About the Project
This project was designed to showcase the various sectors of the Sonalgaz Group, providing detailed insights into:
* **Power Generation**: Visualizing the production and transport of electricity.
* **Gas Distribution**: Specialized modules for gas network management.
* **Corporate Heritage**: A detailed historical overview of Sonalgaz and its subsidiary ELIT.
* **Infrastructure Mapping**: Interactive sections for distribution and transport maps.

## 🚀 Key Features
* **Multi-Page Architecture**: Organized into specific modules (Electricity, Gas, ER, History) for better user navigation.
* **Rich Asset Integration**: Utilizes high-quality industrial imagery and maps to represent energy flows.
* **Responsive UI**: Styled with custom CSS to ensure a professional look across different screen sizes.
* **Technical Documentation**: Includes a structured Q&A / Answer module for web-related technical queries.

## 🛠️ Tech Stack
* **HTML5**: Semantic structure for all industrial and corporate pages.
* **CSS3**: Custom layouts (Flexbox/Grid) for a cohesive corporate identity.
* **Assets**: Optimized JPEG/WebP images for infrastructure visualization.

## 📂 Project Structure
* `Sonalgaz.html`: The main gateway to the group's services.
* `Electricity.html` & `gaz.html`: Technical dashboards for the energy sectors.
* `history.html`: Chronological evolution of the company.
* `Elite.html`: Specialized portal for ELIT technical insights.
* `/img`: A library of 20+ professional assets, including logos, distribution maps, and production icons.
